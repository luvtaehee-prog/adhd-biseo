# 데이터 작성 기준

## 한 행의 의미
**하루 동안 한 프로젝트에 쓴 작업 1건**입니다. 같은 날 여러 프로젝트를 했으면 여러 행이 됩니다.

| 필드 | 설명 | 예 |
|---|---|---|
| id | 행 번호 | w100 |
| date | 작업 날짜 | 2026-09-26 |
| value | 작업 시간(분) | 260 |
| memo | 한 일 | 학부모 공유자료 Vol.01~12 제작 |
| project | 프로젝트 | 인스타 자료 |
| category | 분류 | AXOLVE / 교육콘텐츠 / 학습 / 개인 |
| source | 시간 산출 방법 | 측정 / 추정 / 문서 |

## 작업 시간(value) 계산

| source | 근거 | 방법 | 행 수 |
|---|---|---|---|
| 측정 | Claude Code 대화 기록 (9/1~9/27) | 대화·도구 실행 사이 간격을 더함. 20분 넘게 비면 쉰 것으로 보고 뺌. 5분 단위로 반올림 | 44 |
| 추정 | 파일 수정 날짜 (2월~9월) | 그날 바뀐 파일 수로 추정: 1~2개 30분 · 3~10개 60분 · 11~50개 120분 · 51개 이상 180분 | 61 |
| 문서 | MASTER BOARD 변경 기록 (8/24) | 보고서에 적힌 작업을 시간 추정 | 4 |

- **측정** 값은 Claude와 함께 작업한 시간이라 실제 작업 시간보다 적을 수 있습니다.
- **추정** 값은 파일이 남은 날만 잡히므로 회의·전화·오프라인 작업은 빠져 있습니다.
- 틀린 값은 서비스의 데이터 관리 화면(수정/삭제)에서 고칩니다.
